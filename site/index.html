常见问题

阅读、购买、模型，
以及你的研究资料。

已购买，如何恢复？

在 App 设置中打开“解锁完整版 / 恢复购买”，选择“恢复购买”。设备需使用购买时的 Apple 账户。研映无需另行注册账户；购买和恢复由 Apple 处理。

如何开始自己的研究？

解锁后，在“模型与 API”中保存模型服务、模型名称和自己的 API 密钥，并测试连接。添加研究方向、选择搜索源后，先更新论文，再选择速读目标语言和生成数量。可以手动生成，也可开启自动生成。

速读基于取得的论文标题和作者摘要整理。阅读重要结论时，请结合原论文核对。

更新或生成失败怎么办？

先在模型设置测试连接，再检查密钥、模型名称、服务商额度，以及研究方向绑定的搜索源。任务记录可帮助区分网络、来源或模型响应问题。使用自定义代理时，也请检查代理配置。

如何使用设备上的网页端？

在“设置 → 高级设置 → HTTP 与网页服务”查看当前设备的地址。其他设备需能连接到该地址，并让研映保持在前台或分屏显示。网页与 App 使用同一份本机资料，App 进入后台后网页服务会暂停。

网页服务默认开启，使用未加密的 HTTP，当前没有访问密码。能连接到服务的设备可浏览资料并操作配置和任务。请仅在可信网络使用，不需要时在上述设置中关闭。

如何备份资料？

在设置中导出 JSON 资料副本，包含论文、速读、收藏、笔记、回收站和研究配置，不含 App 保存的模型 API 密钥及代理密码。请自行保管导出文件。

回收站会永久删除文章吗？

移入回收站会保留文章，用于阻止后续重复推荐；可从回收站恢复。删除研究方向或搜索源会停止相应后续抓取，已有论文与速读仍保留。

怎样提交问题反馈？

发送邮件至 luo980@gmail.com，附上设备型号、系统和 App 版本、操作步骤与报错内容。截图请遮盖 API 密钥、代理密码及其他私人信息。

了解资料如何保存与使用

论文与速读保存在当前设备；检索和生成会连接你所选的外部服务。隐私政策说明密钥、购买、本机网页服务及资料管理方式。
