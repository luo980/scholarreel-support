Common questions

Reading, purchases,
models and your data.

How do I restore my purchase?

Open the purchase section in Settings and choose Restore Purchases. Use the Apple Account used for the purchase. ScholarReel requires no separate app account; Apple handles purchases and restoration.

How do I start my own research?

After unlocking, open Models & API to save your provider, model and API key, then test the connection. Add a research topic and select its sources. Update papers, then choose a target language and how many briefs to generate. You can generate manually or enable automatic generation.

Briefs use the available paper title and author abstract. Check important findings against the original paper.

What if an update or generation fails?

Test the model connection, then check the API key, model name, provider quota and the sources selected for your topic. Task history helps identify network, source and model response errors. If you use a custom proxy, check its configuration too.

How do I use the on-device web interface?

Open Settings → Advanced Settings → HTTP & Web Service to see the device’s current addresses. The other device must be able to reach that address. Keep ScholarReel in the foreground or in split view. The web interface uses the same local data as the app; the service pauses when the app goes into the background.

The web service is enabled by default. It uses unencrypted HTTP and currently has no access password. Devices that can reach it can browse your library and operate settings and tasks. Use it on trusted networks and turn it off when you do not need it.

How do I back up my library?

Settings lets you export a JSON copy containing papers, briefs, favorites, notes, Trash and research configuration. App-managed model API keys and proxy passwords are excluded. Keep exported files in a location you trust.

Does Trash permanently delete papers?

Trash retains a paper to prevent repeated recommendations. You can restore it from Trash. Removing a research topic or source stops its future fetching but keeps existing papers and briefs.

What should I include in a support request?

Email luo980@gmail.com with your device model, operating system and app versions, the steps you took, and any error message. Hide API keys, proxy passwords and private information in screenshots.
