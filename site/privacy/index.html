研映（ScholarReel）在设备上保存研究资料，并在你使用检索和生成功能时连接所选的外部服务。以下说明 App 如何处理资料，以及你可以如何管理它们。

设备上保存的资料

App 保存论文及摘要、生成的速读、研究方向和关键词、搜索源、模型与代理配置、收藏、阅读状态、笔记、任务记录及回收站记录，用于阅读、检索、生成和避免重复推荐。

模型 API 密钥和代理密码保存于 Apple Keychain。App 使用仅限本设备、不同步到 iCloud Keychain 的存储设置。密钥填写时显示明文；保存后，普通配置读取接口不返回已保存密钥。

当前 App 无需注册独立账户，没有开发者运营的资料同步服务，也未集成广告或使用行为分析 SDK。App 资料仍可能受你选择的系统设备备份方式影响。

检索、模型与其他外部服务

  • 论文来源：设备向所选来源请求论文列表，或按其接口发送检索词。来源包括 arXiv、Hugging Face 以及你配置的其他来源。打开原文或 PDF 时，会访问相应网站。
  • 模型服务：生成检索词时发送研究方向标题与关键词；筛选相关性和生成子类时发送方向信息、论文标题和摘要、论文标识及已有类别；生成速读时发送论文标题、摘要、所属方向、原文链接和目标语言等生成要求。设备将这些内容和用于鉴权的 API 密钥发送到你配置的模型地址。当前流程不把你的收藏和私人笔记作为模型输入。
  • 网络代理：启用代理后，相关网络连接按你的配置经由代理服务；代理服务会处理连接信息及配置的代理认证信息。

这些连接由设备发起，不经研映开发者的中转服务器。服务商或网站会接收请求所需的网络信息，例如 IP 地址，并按各自的政策处理收到的内容；其存储、日志和保留期限由该服务决定。请在输入研究描述、选择模型、搜索源或代理时考虑其中是否含有私人或未公开资料。

Apple 购买

一次性购买由 Apple 处理。App 使用 StoreKit 验证购买状态、解锁功能和恢复购买，不要求研映账户，也不读取你的银行卡资料。Apple 对购买和支付信息的处理遵循其相关政策。

本机网页与 HTTP 服务

网页服务默认开启，App 在前台时可通过设置中列出的地址访问。它共享本机论文、速读、笔记、收藏、研究与非秘密配置、任务记录等资料，并允许执行相应管理操作。

当前服务没有访问密码，使用未加密的 HTTP。能连接到服务的设备可以访问这些资料及功能；从网页填写的密钥和密码也通过该 HTTP 连接传输。保存到 Keychain 不会加密这段传输。请在可信网络中使用，或在“设置 → 高级设置 → HTTP 与网页服务”关闭服务。App 进入后台时服务暂停。

保存、导出与删除

资料保留在本机供你后续使用。你可以修改笔记、取消收藏、删除研究或模型配置，并在模型或代理设置中清除已保存的密钥、密码。删除研究方向或搜索源不删除已有论文和速读。

回收站保留文章及其标识，用于过滤重复推荐，支持恢复；移入回收站不等于永久删除。导出的 JSON 包含论文库、阅读资料、回收站及研究配置，不包含 App 管理的模型 API 密钥或代理密码。

如需移除整个本机论文库，可在系统中选择删除 App；“卸载 App / Offload App”会保留文稿与数据。Keychain 记录可能在删除 App 后保留，因此请先在 App 内清除不再需要的密钥和密码。你自行保存的导出副本、系统备份及第三方服务持有的数据需分别管理；删除本机资料不会删除这些副本。

联系与政策更新

你联系支持时，我们会收到你主动提供的邮箱、问题描述和附件，用于回复和处理问题。请勿发送 API 密钥或密码。如需咨询隐私或请求处理已发送给支持的资料，请联系 luo980@gmail.com。

App 的资料处理方式变化时，我们会更新本政策及生效日期。

本支持网站

本支持网站由 GitHub Pages 托管，未加入分析脚本、广告或信息提交表单。GitHub Pages 会为安全目的记录并保存访问者 IP 地址；相关托管访问数据按 GitHub 的隐私政策处理。点击邮箱链接会打开你选择的邮件应用。
